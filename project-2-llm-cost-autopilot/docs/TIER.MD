# Complexity tiers

| Tier         | Meaning                               | Baseline prompt IDs |
| ------------ | ------------------------------------- | ------------------- |
| 1 — simple   | Extract, reformat, yes/no, arithmetic | 0, 1, 2, 8          |
| 2 — moderate | Summarize, classify, short structured | 3, 4, 7, 9          |
| 3 — complex  | Compare, multi-constraint reasoning   | 5, 6                |
